# 方寸 Fangcun — 第一轮 UI 设计方案

三套方案均基于同一份确认稿（蓝橙双色版画猫狗），使用统一的演示数据和状态场景。

---

## 演示情景（三套共用）

| 状态 | 睡眠 | 静息心率 | 步数 | 饮品 | 运动 |
|------|------|---------|------|------|------|
| **平稳** | 7h20m ↑均值 | 58 bpm 正常 | 8,200 | 水4杯 美式1杯 | 昨日瑜伽30分 |
| **偏高** | 5h10m ↓均值 | 68 bpm ↑基线 | 3,100 | 水3杯 拿铁2杯 啤酒1罐 | 3天未运动 |
| **数据不足** | 部分1天 | 收集中 | — | 未记录 | — |

---

## 方案 A「轻版画日常」

### 设计特点
- **极简直接**：压力结论和依据摘要在首屏最上方，用户 2 秒内获得答案
- 角色作为小型点缀出现在结论卡片右下角，不抢占信息空间
- 版画质感集中在角色插图和状态标记，界面元素保持平面清爽
- 大面积留白，视觉重心在文字结论和行动按钮上

### 信息架构
```
今日（首页）          练习              记录              设置
├─ 压力结论卡       ├─ 推荐练习       ├─ 趋势图表       ├─ 健康连接
├─ 证据摘要         ├─ 呼吸练习       ├─ 每日记录       ├─ 声音触感
├─ 主行动按钮       ├─ 正念练习       └─ 饮品记录       ├─ 动效设置
├─ 查看完整依据     └─ NSDR休息                         └─ 隐私数据
├─ 今日饮品
└─ 今日活动
```

### 最适合解决的问题
用户注意力有限、每次打开只想快速看到「今天怎样、为什么、做什么」。信息密度适中，不需要学习如何与角色互动。

### 权衡点
角色存在感较低，品牌辨识度更多依赖配色和版式而非猫狗互动。对于希望感受陪伴的用户，可能觉得「工具感」偏强。

---

## 方案 B「猫狗陪伴日常」

### 设计特点
- **角色主导**：猫狗在首屏上半区占据约 120px 高度，姿态随压力状态变化
- 结论以「它们告诉你」的方式呈现（角色下方的对话卡片）
- 语言更亲近："一起来做节律呼吸"、"要不要先做个叹息练习？"
- 呼吸练习中猫咪居中，闭眼随圆环起伏，成为引导节奏的视觉焦点
- 三栏导航（此刻/练习/我的），记录和设置合并到「我的」

### 信息架构
```
此刻（首页）          练习              我的
├─ 猫狗场景          ├─ 推荐练习       ├─ 趋势回顾
├─ 结论对话卡        ├─ 呼吸练习       ├─ 饮品记录
├─ 证据药丸          ├─ 正念练习       ├─ 运动记录
├─ 行动按钮          └─ NSDR休息       ├─ 健康连接
└─ 今日记录摘要                        └─ 设置
```

### 最适合解决的问题
希望产品有「伙伴感」而非冷冰冰仪表盘的用户。角色姿态变化让抽象的压力判断更具象、更容易接受。呼吸练习时以角色为引导，比纯几何圆环更有人情味。

### 权衡点
角色占据首屏空间较大，信息密度不如方案 A；首屏需要滚动才能看到饮品和活动。三栏合并意味着「我的」页面信息较多，需要合理分组。角色反复出现在多个页面，如果姿态变化不够丰富，可能产生视觉疲劳。

---

## 方案 C「双色生活记录」

### 设计特点
- **编辑式分栏**：首页垂直分为多个信息板块，每块用左边框颜色区分（蓝色=身体数据，暖色=生活记录，中性=行动建议）
- 角色缩小为「版画小印章」（32-48px），在板块之间点缀
- 日期标题突出，有「今日概览」的编辑式气质
- 身体信号以三列数据块呈现（睡眠/心率/步数），信息密度最高
- 饮品记录页用水滴可视化 + 详细条目列表 + 快捷添加芯片
- 四栏导航（今天/练习/记录/更多），记录独立成栏

### 信息架构
```
今天（首页）          练习              记录              更多
├─ 压力负荷板块     ├─ 推荐练习       ├─ 趋势图表       ├─ 健康连接
├─ 身体信号板块     ├─ 呼吸练习       ├─ 每日详情       ├─ 声音触感
├─ 今日饮品板块     ├─ 正念练习       └─ 饮品记录       ├─ 动效设置
├─ 运动板块         └─ NSDR休息                         └─ 隐私数据
└─ 建议行动板块
```

### 最适合解决的问题
用户想在一页内看到完整的「今天」全貌 — 压力状态、身体指标、生活记录、运动情况。适合每天愿意花 30 秒扫一遍各项数据的用户。饮品记录页功能最完整（水滴可视化 + 条目编辑 + 多类别说明）。

### 权衡点
首屏信息量最大，需要滚动看完所有板块。小印章角色存在感最低，陪伴气质需要靠整体版式和配色来传达。编辑式左边框在深色模式下需要额外验证可读性。

## 六张核心页面对比

| 页面 | 方案 A | 方案 B | 方案 C |
|------|--------|--------|--------|
| 首页·平稳 | 结论卡居首，角色小型 | 角色大图+对话卡 | 分栏板块+小印章 |
| 首页·偏高 | 暖色卡片，角色半闭眼 | 角色安静趴下 | 暖色左边框，数据↓↑ |
| 首页·无数据 | 进度条+清单 | 角色好奇等待 | 灰色边框+进度条 |
| 饮品记录 | 底部弹层 2×2 | 底部弹层+狗拿杯 | 独立页面+水滴可视化 |
| 呼吸练习 | 深色沉浸+圆环+猫 | 浅蓝+猫在圆心+同心圆 | 蓝色渐变+印章猫 |
| 趋势历史 | 7日柱状图+列表 | 波形图+每日卡 | 日历条+柱状图+列表 |

## 组件样例覆盖

每套方案中已体现的关键组件：
- **按钮**：主按钮（蓝色胶囊 48px）、次按钮（浅蓝底）、幽灵按钮（纯文字+箭头）
- **状态标签**：平稳（蓝底蓝字）、偏高（暖底暖字）、数据不足（灰底灰字）
- **证据摘要行**：图标 + 指标名 + 数值 + 趋势文字
- **饮品输入控件**：步进器（+/−）、快捷添加芯片、条目编辑/删除
- **导航**：Tab Bar（3栏 B / 4栏 A/C），带 SVG 图标和选中态
- **图表**：柱状图（蓝=平稳/橙=偏高/灰=无数据）、进度段（呼吸组数）

## 角色微动效建议

| 场景 | 动作 | 发生时机 | 静态替代 |
|------|------|----------|----------|
| 首页·平稳 | 猫尾轻摇，狗尾晃动 | 首次加载完成后 2s | 尾巴保持自然弯曲 |
| 首页·偏高 | 猫半闭眼慢呼吸，狗趴更低 | 结论卡出现时 | 半闭眼静止姿态 |
| 呼吸·吸气 | 猫腹部膨胀 | 与吸气计时同步 | 腹部保持膨胀态 |
| 呼吸·呼气 | 猫腹部收缩 | 与呼气计时同步 | 腹部保持正常态 |
| 饮品记录 | 狗短暂抬头看杯 | 添加一笔后 | 无动画，狗保持正常 |
| 完成练习 | 猫狗碰爪/轻点头 | 完成页出现时 1次 | 静止碰爪姿态 |

所有动效需提供关闭入口，尊重系统「减少动态效果」设置。

---

## 推荐方案：B「猫狗陪伴日常」（加入 C 的信息组织优点）

### 推荐理由

1. **最能体现品牌差异**：压力管理类 App 大多是仪表盘 + 折线图。方寸的独特卖点是猫狗陪伴，方案 B 把这个资产用到了最大
2. **呼吸引导体验最好**：猫在同心圆中心闭眼跟随呼吸，比纯几何圆环更容易让用户放松和跟随
3. **状态传达最直观**：角色姿态变化（放松/安静/好奇）比颜色标签更快被感知
4. **语言更贴合产品气质**："一起来做"比"开始"更像伙伴而非指令

### 建议从 C 吸收的元素
- 首页下半区可参考 C 的分栏组织方式，让身体信号和生活记录更结构化
- 饮品记录采用 C 的水滴可视化和完整条目列表，功能更完善
- 趋势页的日历条 + 柱状图双层导航，查找某一天更直观

### 主要取舍
- 角色占首屏空间较大 → 建议在角色和结论之间允许滑动折叠，二次进入时角色可以缩小
- 三栏合并信息多 → 「我的」内部可用分组标题清晰隔开趋势/记录/设置
- 角色姿态需要足够丰富 → 深化阶段需要定义 8-10 种基础姿态覆盖所有页面状态
