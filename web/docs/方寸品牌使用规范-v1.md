# 方寸 · 留一方余地

2026-09-18：在用户认可的标志基础上整理应用规范。保留两段软弧的原始路径，不修改已选定的猫狗原画。

## 寓意与品牌语

在纷乱的日常里，留一小处照顾自己的空间。

日常用语：给自己，留一点空间。

标志表达容纳和留白；猫狗在观察、饮品记录、休息及呼吸练习中提供具体陪伴。

## 颜色与尺寸

版画蓝 #1B355A 为主色，暖纸白 #FAF9F5 为背景，柔橙 #E07A5F 仅作为局部点缀。深色背景使用白色标志；深蓝 App 图标保留少量橙色。

16 px 使用单色标志，24 px 起可使用双色。标志四周留出至少宽度 1/4 的空间。不要拉伸、旋转、封闭开口或额外套框；不要在小尺寸添加版画颗粒。

页头以现有系统中文字体搭配，建议字重 600、字距约 0.1em。展示中的中文字标仍为系统字体，不是定制字体或已转曲的商业字标文件。
