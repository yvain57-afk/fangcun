# 方寸 · 方案 C 可视化预览

本机地址：http://127.0.0.1:4174/

打开 `index.html` 也可以离线查看。无需安装依赖。

提供单页切换和六屏总览；每屏内部可滚动，支持原尺寸单独打开。Claude 原稿的 6 个 HTML 文件及图片保持不变。此版本为静态设计评审预览，未实现饮品记录、计时等业务交互。附带的设计说明包含 A/B/C 比较，但压缩包实际仅提供方案 C 的六屏。

原 ZIP 位于 `<LOCAL_HOME>/Downloads/方寸UI设计稿-方案C.zip`。原始哈希记录见 `source-receipt.json`。

启动本地服务：

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

此目录与上一版原型、原生 App 分开，未覆盖其代码。网页中的日期、计时和健康数值均为原稿示例。
