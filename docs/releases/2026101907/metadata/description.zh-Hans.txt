给自己，留一次慢呼吸。

方寸是一款以呼吸与身心练习为主的日常陪伴 App。可爱的猫狗陪你练习，通过清楚的文字、阶段提示和轻柔动作，让每一步更容易跟上。

九种练习，按当下需要选择
• 生理性叹息：紧绷时，先缓一缓。
• 节律呼吸：忙碌之后，慢下来。
• 均衡慢呼吸：找回均匀的节奏。
• 方块呼吸：开始工作前，收回注意力。
• 膈肌呼吸：练习轻松、不费力的呼吸。
• 交替鼻孔呼吸：跟随左右，专注当下。
• 冥想：给纷乱的念头一点空间。
• NSDR：躺下来，让身体休息。
• 凯格尔：练习盆底的轻收与放松。

看得懂，也跟得上
呼吸练习提供吸气、补吸、呼气或停留的阶段提示；猫狗动作与练习时间同步。支持暂停、继续和提前结束。冥想、膈肌与休息练习保留自然呼吸，不必勉强跟拍。

把日常照顾也放在心上
在“日常”中查看身体状态参考和依据、记录饮品与当下感受，选择简单的休息或舒展行动。水、咖啡、酒与含糖饮料可以轻量记录，也能补记、编辑和撤销。

由你决定节奏
支持深浅色、大字号和减少动态。健康连接按需开启；基础练习无需登录账号。练习记录和个人偏好保存在设备上。

方寸提供一般身心练习与自我记录，状态分仅供日常参考，不用于诊断、治疗或替代医疗建议。练习时以舒适为准，不舒服时可以随时停止。
