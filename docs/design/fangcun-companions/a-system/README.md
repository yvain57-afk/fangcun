# A 方向角色系统基准

## 决策

- 第一视觉卖点是“极度可爱、极萌”；不得再以成年用户为由缩小眼睛、减淡腮红或削弱圆润感。
- 成年感由克制的动作、留白、节奏和语言承担，不由降低角色萌感承担。
- 本目录六张图由用户从其他 Agent 提供，本任务只做无损归档和一致性审查，不冒充原创生成来源。
- `concept-a-refined.png` 是被用户否决的试验，只保留追溯，不得作为后续身份或风格参考。

## 身份源优先级

1. `猫狗正面角色锚点.webp`：正面脸型、眼睛、腮红、整体比例与主配色。
2. `猫狗身高比例与固定花纹图.png`：猫狗约 12% 身高差、固定色块与尾端记号。
3. `猫狗转面表.png`：正面、侧面、背面轮廓与花纹延续。
4. `猫狗六状态表情表.png`：六种状态的眼睑、眉形、嘴角变化；不得改动耳型和花纹。
5. `猫狗三档简化测试.png`：44pt、88pt、176pt 的删减层级。
6. `猫狗五套基础动效关键帧.png`：眨眼、呼吸、耳动、尾动、触碰的基础动作语法。

## 不可漂移特征

- 猫：焦橙头斑、奶油 W 形脸、大颗暖棕豆眼、暖腮红、略不对称竖耳、大前爪、粗短逗号尾及深青尾端记号。
- 狗：蜜糖黄主色、奶油脸胸、大颗暖棕豆眼、暖腮红、一折一垂耳、深青折耳与单侧肩斑、大前爪、钝卷尾；整体比猫约高 12%。
- 共用色：焦橙 `#E96F3F`、蜜糖黄 `#E6A63B`、奶油 `#FFF0D2`、深青 `#397B80`。

## 当前边界

- 六张均为 2048×1152 的探索/说明图，不是 App 页面或正式上架资产。
- 44pt 图是视觉删减方案，不等于已经在真实 SwiftUI 44pt 容器中通过像素级测试。
- 六状态文案“有触动/绷着/有点累/说不清”分别对应原任务的“感动/紧绷/疲惫/不确定”，角色只陪伴呈现，不替用户认定状态。
