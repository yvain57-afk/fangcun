# 方寸原生界面改版 · 2026-09-18

## 已确认的设计来源

以 `web` 的已确认界面、v4 猫狗原画与「留一方余地」标志为准。实现为 SwiftUI 原生页面，不嵌入网页、不在手机里展示网页 Mock 健康数据。

## 原画与动效

七张图片逐字节复制原文件，SHA-256 对应关系保存在交付目录 `character-asset-manifest.json`。不重新绘制猫狗，不修改源 PNG。Metal 采样变形沿用网页里的头部、胸腹及尾巴区域，脚底和纸面边缘固定。有限的点头、碰爪在完成后停止帧时钟，呼吸场景使用练习时钟；页面不可见或后台时暂停。

## 数据与兼容

- 原有 SwiftData 模型与用户记录保留；没有更改数据模型 schema，也没有卸载 App。
- 饮品和身体快照使用独立的本机 UserDefaults Codable 存档，损坏数据不自动覆盖；其他日期的记录不会因今日增减被删除。
- 饮品是预估生活线索，不凭单次摄入重写健康压力结论；总液体包含记录的饮品，酒精不等于补水建议。
- 身体趋势从本次改版开始积累，已有练习记录通过原有 SwiftData 查询继续展示。没有导入网页示例历史。
- 默认首页没有演示切换器；仅 `--ui-testing` 加 `--preview-state=...` 时支持截图测试场景，测试使用临时饮品存储与内存 SwiftData。
