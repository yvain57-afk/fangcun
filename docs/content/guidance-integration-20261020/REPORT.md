# 方寸：新版引导词、可跳过开场与独立肌肉放松

日期：2026-10-20。代码基线：f188b0eff998de340842eff11ccead0130735ad0。开发分支：codex/fangcun-v4-breathing-hub。

## 本轮范围

用户认可上一轮完整审阅稿后，要求接入试用，并允许跳过不想重复听的说明。

- 原九项练习接入已审阅的开场、阶段引导与收尾文案。开场在训练计时之前，听完自动开始；底部常驻“跳过，直接开始”，停止开场音频后进入完整训练时间。
- 支持暂停/继续开场，以及按练习记住“下次跳过这项说明”。后者仅跳过开场，不修改声音模式、音量或训练内的阶段提示。详情页可恢复开场。
- 保留静音、仅节拍、声音音量为零的偏好；这些模式不强播旁白。开场被中断、切后台、拔耳机或退出时不会误启动训练。
- 增加独立的“渐进式肌肉放松”，10 分钟，八组肌肉：双手、上臂、额头、嘴唇与面颊、肩膀、大腿、小腿、双脚与脚趾。每组听动作说明 20 秒、很轻地收紧 5 秒、松开 25 秒；保留自然呼吸，不伪装成周期吸呼练习。
- 提供日间温和唤回与睡前安静休息两种结尾。睡前完成后自动保存本机记录，不强迫填写感受。收紧中暂停后，剩余收紧时段改为休息，不追加补做，也不把完整长语音挤入剩余短时段。
- 原有认可的猫狗素材、练习视觉与呼吸动作继续使用。本轮没有重新拼画或拉伸角色；肌肉放松以完整休息姿态陪伴，动作部位、阶段、倒计时和进度承担操作提示。

## 参数与数据边界

PracticeCatalog.v4 原九项及旧 buildOne、Watch 五项入口参数保留；新增 phone 目录追加肌肉放松。原九项 19 种时长/变体组合、自然引导六条轨道共 62 个段落边界不变。开场不计入有效时长，不写入训练区间，不挤占原节拍。

没有数据库字段变更、清库或破坏性数据迁移。读取处新增 PMR 专属协议标识的准确匹配，原 V4 与无元数据的旧记录继续按原路径读取；未知版本或损坏元数据仍保留原字节并拒绝当作旧记录重写。PMR 完成和反馈入口明确只保存本机，不请求 HealthKit 写入。新偏好使用独立的按方法存储键；PMR 使用新增 PracticeKind 和独立协议标识，原记录仍可解码。PMR 不自动推荐、不新增健康写入与权限。评分实现、golden fixtures 与 entitlements 的字节核对见 PRESERVED_BASELINES.json。
