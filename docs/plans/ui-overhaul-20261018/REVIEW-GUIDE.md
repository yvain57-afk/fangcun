# 给复核 Agent 的阅读顺序

本轮目标是原生 iOS 整版 UI/UX 改造。请先看 `修订执行规格.md`、`改动与验证报告.md` 与 `角色素材与动作.md`，再打开 `界面与动画总览.html`。截图为合成数据下的真实 App 截图，多个滚动位置/阶段不是独立页面。

优先复核：
1. 九种练习的角色完整性、姿态识别、吸气/呼气/补吸/停留/收缩与放松的视觉指引；暂停是否停止，继续是否按原策略恢复。
2. 自然呼吸、冥想和 NSDR 是否避免伪造定时吸呼；交替鼻孔是否清楚标明用户左右；凯格尔是否避免引导收腹。
3. 首页用途与时长是否清楚，详情、开始、退出、反馈、保存与回到记录的链路是否完整。
4. 日常状态与依据、趋势缺测、饮品复合记录/编辑/撤销、感受、轻行动、设置与清除确认的可用性。
5. 深浅色、最大辅助字号、减少动态下的可读性及主操作可达性。

请将问题对应到具体截图文件或录像时间点，区分视觉偏好、交互缺陷与模型问题。保留原训练参数、状态分模型、golden fixtures、健康权限和现有用户数据；本轮未授权重写这些部分。
