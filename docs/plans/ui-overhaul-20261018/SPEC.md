## 不变量
不改 Core 训练参数、状态模型、golden fixtures、数据库结构、健康权限、声音资产及用户偏好键。不清库、不自动发布、不上传健康资料。
训练展示唯一事实来源是 PracticeTimeline；生理性叹息 3/2/7，节律 4/6，均衡 5/5 或 4/4，方块 3/3/3/3，交替左右四段各 3 秒不屏息，凯格尔 4/8，膈肌/冥想自然呼吸、NSDR 实际分段引导。
保留五分钟呼吸主入口，一分钟为体验入口。时长按钮只能来自 PracticeCatalog。

## 采用与修正
- 采用全站纸白/蓝墨/松石绿、克制陶土橙，明暗模式，动态字体，统一纸卡和二级列表。
- 首页展示用途、动作和实际节拍；详情前置动作、时长与开始，教学和音效设置渐进展开。
- 不采用“急性降压”“60 秒胸闷消退”“神经实证”等无法测量的效果保证。只描述用途、操作、实际完成的引导和主观反馈。
- 完整原画角色保留；新增由 imagegen 制作的完整休息姿势。局部连续形变不拆头耳，不整体缩放。自然呼吸动画标示为示意，不强加节拍。凯格尔以教练信号提示，不误导用户收腹。
- 角色后方低对比柔光，阶段轨在下方；宽度按真实秒数分配，小段标签外置。颜色不是唯一指令。
- 暂停冻结姿势与时间；减少动态/低电量采用静态阶段提示。视觉、音频、触觉仍读取同一会话时钟。
- 完成页使用“本次练习记录”；统计的是已播放引导，不声称测得实际呼吸或生理改善。
- 不制造趋势基线带；仅呈现已有真实分数与缺测状态。
- 饮品四类仍为水、咖啡、酒、糖饮，保留复合记录和撤销。常规字号两列，自适应弹层；大字号全高滚动。保留键盘精确输入，增加常用容量。
- 主操作优先，不以限制辅助字号挤满首屏；长内容允许滚动。关闭/继续提供明确按钮，不用坐标手势替代可访问控件。
- 保留稳定 accessibilityIdentifier 与业务断言；采集脚本适配正常 UI，不为了脚本误操作损害用户行为。
