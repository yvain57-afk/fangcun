# 方寸整版 UI 改造 · 交付核验

执行基线：`b882c02b23091776488b6518089cbd6d91832a5c`，分支 `codex/fangcun-v4-breathing-hub`。本轮按用户确认的修订规格整版实现，保留现有训练、记录与权限边界。

## 已实现

- 呼吸首页改为用途明确的方法卡，展示真实节拍和时长选择；保留五分钟主入口与一分钟体验。详情把动作、时长和开始前置，原教学和声音设置可展开。
- 保留六张认可的完整原画；imagegen 新增蜷卧猫与枕爪睡狗。整幅角色不再拆头、拆耳或整体缩放。局部胸腹、背部和教练旗子由实际训练时间线驱动。左右换边、补吸、停留和释放有文字、阶段轨与动作配合。
- 呼吸柔光在角色后方，实际阶段轨按秒数分配宽度。暂停冻结当前姿态；恢复沿用原来的准备策略。剩余时间固定在底部。自然呼吸、冥想和 NSDR 不添加强制吸呼节拍。
- 退出弹层明确提供继续/结束；打开时暂停，取消后只恢复原先正在进行的会话，原本暂停的会话保持暂停。最大字号可滚动。
- 日常状态、证据、趋势、饮品、感受、轻行动、记录和设置统一纸白/蓝墨/松石绿视觉。深浅色和系统辅助字号保留。
- 饮品快捷记录保留四类、甜拿铁复合记录与撤销；编辑增加常用容量，保存键固定，保存后收起键盘并显示记录。数据命令与撤销语义不变。
- 完成页统计实际播放的引导轮次，明确是引导记录，不声称测得实际呼吸或生理改善。

## 保留范围

`invariants.json` 核验 Core、持久化、健康读取、草稿存储与 entitlements 相对基线没有改动。训练参数、状态分模型、固定样例、数据库结构、偏好键、语音资源均保留。本轮未清库、未上传个人健康内容、未自动安装手机、未发布 TestFlight 或 App Store。

## 真实边界

模拟器通过不代表真机验收。本轮没有验证真实 HealthKit、Watch 后台/跨设备同步、真机锁屏音频、扬声器效果或触觉；这些能力没有被写成通过。视频是原生界面的视觉录像，不包含设备音频。保留的 Xcode/系统警告包括 receipt API 弃用、AppIntents 元数据跳过、模拟器 SDK 版本解析及内部 QoS 警告。

## 复核说明

这次只更改显示与交互层，未修改或迁移用户数据库；实际手机中的历史记录是否在覆盖安装后完整保留，仍需真机核对。测试和录像使用隔离的合成存储。

视频为模拟器的可变帧率录屏。最初直接送入 FFmpeg 默认 null 输出时有输出时间基导致的 DTS 警告；最终采用 fps=30 的空输出验证完整解码，未改动原始录像。此项不是 App 训练时钟错误。
