# 九项练习与功能文案

本文中的功能标题、用途和完成回顾是新版本界面文案。九项全部交付；实际节拍与类型以 `config/practices.v4.json` 为结构化对应。既有类型保留身份，历史不重新解释。

## 1. 舒缓紧张｜生理性叹息

**卡片用途：**用两次轻吸和一次长呼，放慢急促的呼吸，松开紧绷感。

**适用时刻：**突然紧张、忙碌间隙，或想先缓一缓。

**具体怎么做：**轻轻鼻吸 → 再补一小口 → 用嘴慢慢呼出。

**时长：**1 / 5 分钟；建议默认5分钟。

**完成页回顾：**完成了一段舒缓呼吸练习。

**播放器类型：**`pacedBreath`；专属场景`cat_flower_sigh`。

**方法提示：**轻柔呼吸，不必吸满；头晕或不舒服时停止，恢复自然呼吸。

**开发处理：**保留现有方法ID和既有时长；新的呈现/脚本保留版本身份。

## 2. 睡前放松｜节律呼吸

**卡片用途：**把呼气放长，让身体慢下来，为休息和入睡做准备。

**适用时刻：**睡前、一天结束后，或需要安静下来的时刻。

**具体怎么做：**轻轻吸气 4 秒 → 慢慢呼气 6 秒，全程不屏息。

**时长：**3 / 5 分钟；建议默认5分钟。

**完成页回顾：**完成了一段睡前放松练习。

**播放器类型：**`pacedBreath`；专属场景`dog_pillow_exhale`。

**方法提示：**不追求深吸或用力呼尽；节奏吃力时停止，恢复自然呼吸。

**开发处理：**保留现有方法ID和既有时长；新的呈现/脚本保留版本身份。

## 3. 稳住节奏｜均衡慢呼吸

**卡片用途：**用均匀的吸气和呼气，练习稳定、从容的呼吸节奏。

**适用时刻：**日常固定练习、工作间隙，或喜欢简单节拍的时候。

**具体怎么做：**吸气与呼气一样长；默认各 5 秒，也可选各 4 秒。

**时长：**3 / 5 分钟；建议默认5分钟。

**完成页回顾：**完成了一段均衡呼吸练习。

**播放器类型：**`pacedBreath`；专属场景`duo_settled_breath`。

**方法提示：**轻柔呼吸，不必吸满；不舒服时停止。

**开发处理：**新增正式可执行方法，不能只新增目录卡片。

## 4. 进入专注｜方块呼吸

**卡片用途：**跟随吸、停、呼、停四段节拍，把注意力收回到眼前。

**适用时刻：**工作、阅读、演讲准备之前。

**具体怎么做：**吸气 3 秒 → 停留 3 秒 → 呼气 3 秒 → 停留 3 秒。

**时长：**3 / 5 分钟；建议默认3分钟。

**完成页回顾：**完成了一段专注呼吸练习。

**播放器类型：**`pacedBreath`；专属场景`cat_four_corners`。

**方法提示：**含短暂停留。无需忍耐憋气；不舒服时恢复自然呼吸，可换均衡慢呼吸。

**开发处理：**新增正式可执行方法，不能只新增目录卡片。

## 5. 轻松呼吸｜膈肌呼吸

**卡片用途：**学会用腹部和下肋轻柔呼吸，减少肩颈带着用力。

**适用时刻：**想学会不费力的呼吸，或先熟悉身体动作。

**具体怎么做：**手轻放腹部或下肋，感受吸气时轻轻展开、呼气时回落；按自己的节奏。

**时长：**3 / 5 分钟；建议默认3分钟。

**完成页回顾：**完成了一段呼吸动作练习。

**播放器类型：**`guidedNatural`；专属场景`dog_soft_belly`。

**方法提示：**不故意鼓大肚子，不压腹部，不强行深吸；不适时停止。

**开发处理：**新增正式可执行方法，不能只新增目录卡片。

## 首屏文案分工

功能标题先让用户知道来做什么，方法名再说明采用哪种方式。专业名不承担全部解释任务。例如“盆底控制”与“凯格尔”同时出现，避免只写一个陌生词；“恢复精力”“深度休息”与“NSDR”共同呈现，避免用英文缩写挡住理解。

“稳住节奏”与“睡前放松”虽然都含慢呼吸，前者等时，后者延长呼气；两者节拍、姿态、音频和推荐时刻都不同，不增设第三个内容重复的“长呼气法”。

冥想、NSDR、凯格尔继续保有各自功能。凯格尔用自然呼吸配合肌肉训练，不编码成憋气呼吸法；NSDR不编码成10分钟循环吸呼计时器。
