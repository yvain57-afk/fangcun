# 音频与节拍规格

## 已有基础与本轮变化

固定快照已存在PracticeAudioPlan及相关协调器，语音包标识为`zhixingnv`，具有guided/rhythmOnly/silent、短语音、提示音与环境底层的组合。这里只确认源码配置，没有声称已听过所有成品声音。

本轮保留已经认可且能用的声音风格；新增方法使用同一声音身份与音量规范。关键指令必须简短、自然、有空间；不要忽然换成机器播报或夸张疗愈腔。

现有NSDR按每25秒轮换六个cue，冥想也有重复提示循环。本轮用完整的10/20分钟NSDR和5/10分钟冥想段落脚本替换机械重复，新脚本按协议版本记录。时长和旧记录不变。

## 分层与关键指令

语音、节拍、环境声独立音量与静音。语音播出时环境声轻降，结束后平缓恢复。小猫小狗不添加持续喵叫、犬吠或哈欠音；宠物的声音不能盖过方法指令。

生理性叹息：吸气3秒“轻轻吸气”；补吸2秒“再补一小口”；呼气7秒“慢慢呼出”。对应旧素材可复用，实测语音时长必须落在相位内，禁止排队播到下一阶段。

节律：吸气4秒“轻轻吸气”，呼气6秒“慢慢呼气”。均衡：吸气/呼气等时，5/5或4/4。方块：吸气、停留、呼气、停留，各3秒；停留口令短，不渲染憋气的痛苦。

交替鼻孔：完整序列“左侧吸气 / 右侧呼气 / 右侧吸气 / 左侧呼气”，每段3秒，必须明确左右。凯格尔：“轻轻收紧，呼吸照常”4秒；“完全放松”8秒。导语先讲动作，不在每次短相位内塞长句。

节拍口令初始完整，熟悉后可在设置中选仅节奏；交替鼻孔保留足够辨认左右的语音路线，不以同一个铃声假装能传达四种动作。禁止为了让语音播完而悄悄延长原协议秒拍。

## 完整引导脚本

`config/guided_scripts.zh-Hans.v4.json`给出每个段落的开始/结束时间、身体焦点和逐字中文内容，覆盖NSDR10/20分钟、冥想5/10分钟、膈肌3/5分钟。

段落开始说一次，余下为自然停顿/可选环境声。它们不是连续背稿，也不循环同一语音凑时长。身体焦点同时驱动对应猫狗小动作，文字和音频使用同一条segment数据。

NSDR最后30秒收束；冥想最后15–35秒收束。安静结束选择关闭额外完成音效，不自动亮屏；仍正确保存会话。不得播放“已消除全部疲劳”“10分钟抵两小时睡眠”等不存在的测量结论。

## 资产生产与质量

优先使用仓库既有语音制作方式、同一音色及有权使用的素材。以生成/录制后的真实文件时长校验脚本窗口。若原生产管线暂不可用，现有短语音继续可用于已支持方法；新增完整引导列为尚未完成，不能静音冒充完整交付。

所有正式可用的必需音频随包离线可用。缺失文件、时长溢出、音量突变、前后接缝必须进入验收；不让运行时偷偷切到另一音色掩盖丢失资源。

引导模式缺关键音频应给清楚状态并允许使用可用的文字引导，不假称“语音引导已就绪”。NSDR的完整音频是本轮交付项，不能仅因文字版可运行就通过整版验收。

## 时钟、中断和后台

会话由统一活动时间推进，不能将定时器累加、音频循环、角色循环、触觉轮询各做一套。短口令按相位事件调度；完整引导以可同步的播放时间线协调，发生偏移时回到同一逻辑锚点。

现有源码在静音、没有连续音频等条件下暂停后台练习。本轮保留诚实的后台语义：有真正的音频播放且系统允许才持续；不借循环静音音轨、假运动会话等保活。音频中断、耳机断开、App被终止都不得靠墙钟差自动算完成。

恢复时不连续补播所有漏掉的口令；节拍从安全的新动作起点进入，段落音频恢复当前段落/位置，实际计时与恢复策略共同验收。蓝牙设备延迟单独测量，不虚报所有设备零延迟。
