# 产品与交互规格

## 1. 用户打开后立即知道三件事

这里可以做什么练习；这项练习用来解决怎样的当下需要；点击哪里开始。首页主轴是用途、练习与陪伴。所有新增结构围绕“看懂用途 → 开始 → 跟随 → 完成 → 再次回来”。不增加账号、问卷、线上AI、课程商城、宠物养成或积分系统。

定位文案建议：**用呼吸放松，用练习找回专注与身体控制。**
首页品牌副标题：**呼吸与身心练习**。

用户看到的功能文案直接说用途，不塞论文摘要、证据等级或反复的“可能”。练习卡给出清楚的训练目标；结果页显示实际完成时长、练习与用户自选感受，不编造测量结果或自动替用户宣布症状改善。技术性同步文案只在日常页呈现。

## 2. 两个主页面

### 第一页：呼吸

默认启动页，替换现有今日页与练习库的分离结构。保留品牌logo与已有蓝白轻版画体系。

从上到下：

**品牌栏。** 左侧原标志与“方寸”，次行“呼吸与身心练习”。右侧只保留小型练习记录入口。字号与深浅色设置进入日常设置，不在首屏堆工具按钮。

**主练习卡。** 标题首先是功能，例如“舒缓紧张”；下一行“生理性叹息 · 5分钟”；一句说清用途；专属猫狗场景与大按钮“开始5分钟”。默认首次推荐已有生理性叹息5分钟，保留明确1分钟体验。不是所有新用户都被迫学习一遍9项。第一次使用某种方法时出现简短动作提示；之后直接进入。

**轻量筛选。** “全部 / 放松 / 专注 / 休息 / 身体训练”。只是筛选练习目录，不询问用户“你现在是什么情绪”。无需选择即可看见全部。

**全部练习9项。** 默认顺序：生理性叹息、节律呼吸、NSDR、冥想、均衡慢呼吸、方块呼吸、膈肌呼吸、交替鼻孔呼吸、凯格尔。正常字号两列卡片；第九项凯格尔采用同层级通栏卡，不隐藏、不弱化成禁区。大字号改成单列。

每张卡固定展示：功能标题；方法名称；可选时长；一幅该方法专属静态关键姿势。主练习卡可以动，目录不同时跑九段动画。NSDR和冥想处在目录前两排，凯格尔通过“身体训练”筛选直接可达。

**最近完成。** 页面末尾可以有一行真实完成记录，例如“今天练习了8分钟”。点击进入日常的练习记录。首页不画复杂趋势图，不放分数摘要，也不把健康连接以横幅搬回来。

### 第二页：日常

用简单、统一的列表/卡片聚合已有辅助能力。主要模块顺序：

1. 练习记录：按日与按方法查看实际时间、完成/提前结束与可选感受。
2. 身体状态：方寸状态分摘要、构成详情、7/28天历史、手工补记睡眠、Apple健康管理；展开后才显示同步或来源细节。
3. 饮品与关怀：今天喝了什么、水/咖啡因/酒精/含糖饮品、剂量时间编辑、撤销、至多一条已有关怀。
4. 感受记录：沿用现有记录与查看入口。
5. 轻行动：安静休息、座位舒展及已经存在的其他轻行动。

右上角设置进入原设置页，按显示与声音、健康与通知、数据管理、关于整理。已有每项能力必须有迁移去向。先聚合，后续再由用户决定增减，不趁本次重构删除功能。

## 3. 首屏布局规格

沿用背景浅色#FAF9F5、主蓝#1B355A、暖色#C26D54及现有深色token。通用页边距20pt、卡间距12–16pt、主卡圆角24pt，作为初始设计值。最终以原生大小字号与截图校验为准。

标准390pt宽屏上，品牌栏约52pt、主卡约240–270pt，卡内角色表演区约145–170pt高。下方目录标题与至少第一排卡片有明确可见入口。练习卡功能标题17–20pt、方法名13–14pt，正文支持系统字号。不要通过压小文字把所有9项硬塞一屏。

全屏训练角色区域优先获得约260–320pt的可用宽度，实际按屏幕/安全区缩放；标题与操作不能遮住脸、前爪或动作指向。圆环、线条仅作辅助节拍，不能再次成为所有方法的主画面。

## 4. 主卡选择规则

优先继续真实进行中的会话。否则默认显示最近一次用户明确用于快捷开始、且仍适合快捷开始的方法。没有选择时使用生理性叹息5分钟。

睡前可用已有确认睡眠计划轻量优先节律呼吸；无计划则使用本地22:00–06:00。此为场景排序，不改变状态分、不强制自动启动。用户固定的快捷方法优先，主动选择不被时间覆盖。

不因为状态分低、健康没有数据或同步失败而把首页主按钮变成同步、连接或两分钟休息。已有“不想呼吸”的用户可以选冥想、NSDR或日常轻行动；恢复呼吸目录无需重新健康授权。

凯格尔、方块、交替鼻孔不作为全体首次用户的自动推荐。它们在首页完整可见，用户主动选择后可收藏/固定，但须完成各自的简短首次方法教学。保留既有安全条件；无安全条件数据也不推测用户正在驾驶或确有疾病。

## 5. 方法详情页

顶部展示功能标题，再给准确方法名称。下方一句用途，接可选的完整动作示范和“怎么做”，然后时长。主按钮固定在安全区域“开始X分钟”。详情无需滚过长篇说明才找到开始。

节拍方法给清楚相位示意，冥想/NSDR给内容流程，凯格尔给收放与自然呼吸说明。膈肌与交替鼻孔保留身体/手势教学，角色不能替代动作教学。

舒适度调整只做规格中给出的选择，不开发任意极端屏息编辑器。保留已有两种呼吸的秒拍和时长；新增均衡有5/5、4/4，方块仅3/3/3/3，交替鼻孔3/3/3/3无屏息。

## 6. 完整会话

开始前最多一个可跳过的简短准备动作；剧情入场不计入练习时长。进入正式练习后，动作、字幕、音频、触觉同一时间线。当前指令优先，剩余时间次之，暂停和结束始终可达。

暂停时立即释放“屏息/收紧”指令，文字为“已暂停，先自然呼吸”；停止节拍声音和触觉。恢复有短暂不计时准备；节律类从新的吸气起点继续，凯格尔从完全放松状态重新开始下一轮。通过独立相位锚点处理，不能重置已练时长或强迫用户接着憋气。

提前结束先保留实际完成时间和状态，反馈可跳过。暂停时间、详情演示、入场动画不计训练分钟。保存失败显示重试，不能伪造成功反应。恢复成功不重复插入记录。

完成页显示“完成5分钟·均衡慢呼吸”等真实事实，以及对应训练内容回顾。可选“更舒服 / 差不多 / 不舒服”，不默认选正面选项。退出无需填问卷。NSDR/睡前模式在锁屏或暗屏结束后不自动亮屏、播放庆祝声或催填反馈，下次回来再显示安静的记录页。

## 7. 声音与闭眼使用

保留“语音引导 / 仅节奏 / 静音”。方法相位需短而准确，NSDR/冥想则用带自然停顿的完整引导。每种练习可有专属预设，不必新增大量音效主题。

语音模式提供不看屏幕完成整次训练的路线，特别是NSDR、冥想。真正有音频播放且系统允许时支持锁屏延续；静音或无法持续播放时明确暂停，不用虚假静音音轨保活。耳机拔出及通话打断先暂停，不突然转扬声器播出敏感练习内容。静音下交替鼻孔不承诺仅靠相似震动即可闭眼辨别所有步骤。

## 8. 空态和健康权限

新用户完全不授权Apple健康，仍可完成9项练习并本地记账。App不申请麦克风、摄像头或在线账户来“检测用户是否做对”。

日常页无健康数据显示“暂未获得可用数据”，不显示0分或“正常”。Apple健康的读取授权不可按空查询结果推断成“已拒绝”。已有授权继续按原设置在后台或适当时机使用，弱化入口不等于清除用户已开启的同步。

已有权限过期/失败只影响对应日常模块；只读权限和正念写入权限分别处理。完成记录本地保存优先，不等待联网或健康写入。
