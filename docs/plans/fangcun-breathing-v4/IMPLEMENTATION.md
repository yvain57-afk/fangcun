# V4 实现说明

本轮在原生 SwiftUI 工程实施。默认进入呼吸页，九项方法使用原有统一会话、保存与权限协调器；日常保留原状态分、饮品、感受、轻行动及设置。网页原型没有冒充本轮交付。

## 九项方法

| 用途 | 方法 | 时长 | 实际时间线与角色 |
|---|---|---|---|
| 舒缓紧张 | 生理性叹息 | 1 / 5 分钟 | 3 秒主吸、2 秒补吸、7 秒呼气；小猫闻花，胸腹局部追加量小于主吸 |
| 睡前放松 | 节律呼吸 | 3 / 5 分钟 | 4 秒吸、6 秒呼；小狗枕爪，头爪接触保持稳定 |
| 稳住节奏 | 均衡慢呼吸 | 3 / 5 分钟 | 5/5 或 4/4；猫狗各自分层，同一相位驱动，不交替错拍 |
| 集中注意 | 方块呼吸 | 3 / 5 分钟 | 3/3/3/3；猫与四角提示，停留时胸腹不继续起伏 |
| 放松呼吸动作 | 膈肌呼吸 | 3 / 5 分钟 | 完整自然引导段落，无强制呼吸倒计时；侧躺小狗下肋前爪示意，另有人体动作教学 |
| 静心收神 | 交替鼻孔呼吸 | 3 / 5 分钟 | 左吸、右呼、右吸、左呼，各 3 秒；狗与左右叶子，明确“你的左侧/右侧” |
| 减少分心 | 冥想 | 5 / 10 分钟 | 完整分段脚本；猫坐稳，有限的注意力回归动作，不做追逐循环 |
| 恢复精力 | NSDR | 10 / 20 分钟 | 脸、肩、腹、腿等段落焦点分别驱动局部放松；薄毯与侧躺小狗，长停顿降低刷新 |
| 盆底控制 | 凯格尔 | 3 分钟 | 4 秒轻收、8 秒完全放松；狗举落小旗，身体不模拟屏息或腹部用力 |

准确用途、逐字声音和段落时间以 `config/` 与 Core 的 `PracticeTimeline` 为依据。自然引导中的长时间安静是设计的一部分。

## 角色生产与渲染

读取原认可猫狗作为身份参照后生成四张生产图层母版，提取 40 个原始 RGBA 图层。保留奶油白内部，不使用近白去纸算法。源图、提示词、裁切坐标与 SHA-256 见 `art/`、`ASSET_MANIFEST.json`。

`PracticeCompanionV4.swift` 使用原画头、表情、前爪、耳、尾、胸腹和道具组合；仅胸腹使用局部 Metal 形变。脚底、颈部、枕爪支点作为约束。核心训练没有整图缩放或循环 MP4，也没有用程序几何形状代替猫狗。

休息路线入场使用坐姿、伏下、最终侧躺/前趴三张真实关键姿势，最多 4 秒、可跳过、不计时。并肩场景直接由两个独立角色入场，猫轻靠近；其他坐姿用前爪落稳及小幅视线变化收束。成功动作有限且仅在保存成功后发生，提前结束保持平静。

standard/gentle/static、减少动态及低电量被尊重。首页只有主场景活动，目录卡静态；离屏和后台不持续刷新。自然训练动作窗口为脚本段开始 2.4 秒，其余降低为 1 Hz；训练时钟不由绘制帧数累计。

## 统一时间、声音与保存

ViewModel 的单调活动时间提供相位和段落快照。渲染、音频与触觉从同一配置计算，暂停停止输出，恢复前先有 2 秒准备；屏息恢复从新吸气开始，凯格尔恢复先完整放松。准备、暂停、离开后未确认的时间不记成练习。

音频均随包离线播放，保留旧 16 条原文件，新增/派生 70 条。新段落从 Edge TTS 制作，逐字脚本完整，不以短口令轮播冒充 NSDR 或冥想。语音、节奏、环境声有独立音量，播放按当前时间窗截断/seek，不补播过期队列。新增声线与旧声线人工听感、真机输出延迟另行验收。

完成先本地保存，再处理既有健康写入；三选真实反馈可跳过，不填正面感受，不增加状态分。按实际活动区间写正念，稳定会话/区间 ID 保证重试幂等。凯格尔不写正念。

原 SwiftData 记录只新增可选协议 metadata；旧 raw value、历史、声音与显示偏好保留。损坏 metadata 不被当成一段连续旧会话写健康；损坏草稿隔离留存，不能清库掩盖错误。

Watch 保留原五项可执行能力，新记录通过能力协商；旧端不支持的新方法排队保留真实 ID，不改写成旧方法。Watch 模拟器编译和实际配对/后台验证是不同结论。
