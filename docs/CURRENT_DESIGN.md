# 当前设计方向 · 2026-09-18

## 版画日常与情境陪伴

主体为轻版画日常风格，结合情境姿态。暖纸白 `#FAF9F5`、版画蓝 `#1B355A` 与克制的橙色点缀；原生深色使用独立色值而非简单反相。卡片、按钮、留白与字体服从手机阅读和 Dynamic Type。

“方寸”指内心的一小片空间，也指繁忙日常中留给自己的余地。当前标志为带开口的环抱形，保留呼吸的空隙。已淘汰“方”字加方框的字面做法。完整寓意与应用见 `web/docs/` 品牌文档、`web/brand-studio.html`。

## 角色定案

主角色使用 `web/public/characters/v4/` 的确认稿。猫咪圆润、短肢、蓝色线条和橙色耳部；小狗已重新设计为圆脸垂耳，避免旧版比例问题。呼吸猫咪沿用 v3 的闭眼坐姿。图像必须保持原有特征，不能为了写 SVG 而改成几何占位图。

| 情景 | 角色 | 动作 |
| --- | --- | --- |
| 平稳 | 猫狗相伴 | 低频、轻微的头部和尾巴动作 |
| 偏高 / 休息 | 小狗单独趴着 | 安静的胸腹起伏 |
| 数据不足 | 猫咪单独观察 | 小幅歪头、好奇观察 |
| 饮品记录 | 小狗与水杯 | 记录后有限次点头，不持续表演 |
| 呼吸练习 | 猫咪独处 | 胸腹与练习时钟同步，暂停冻结 |
| 完整完成 | 猫狗碰爪 | 有限的庆祝动作 |
| 提前结束 | 休息小狗 | 平静陪伴，不用失败反馈 |

## 交互原则

- 首页先看到结论、依据和开始入口。取消强制的预设状态标签。
- 保留真实数据边界：压力 / 负荷判断必须有可查看依据，未知不能包装成平稳。
- 饮品半屏弹层支持复合增减和撤销，不让轻记录变成问卷。
- 5 分钟练习直接开始；暂停、继续、安全退出和保存都属于完整验收。
- 支持系统及 App 内减少动态效果；角色不抢夺主操作的注意力。
- 深色与大字不能只改背景和字体变量，仍需查看真实页面布局。
